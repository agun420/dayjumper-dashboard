# DayJumper Observatory redesign

Apple-inspired typography, restrained color, spacious panels, a dark status card, light/dark appearance toggle, responsive layout, ticker search and sorting. Original frozen rank stays visible when sorting. Tables scroll inside the card on narrow screens. Keyboard controls, skip navigation and reduced-motion support are included. No external fonts or CDN dependencies.

Publication dates and a historical-snapshot notice distinguish old watchlists from current-date publications. This static view does not claim live market prices, successful live capture, or verified profitability. All supplied data files remain unchanged. Null metrics remain unavailable rather than becoming zero. Reported session count is labeled as reported, not independently verified.

## Install on GitHub Pages

Copy index.html, assets/app.js and assets/style.css into the corresponding paths of your dayjumper-dashboard checkout. Commit and push via GitHub Desktop. Keep the existing data directory and publisher-generated files; do not overwrite fresher data with the ZIP's September 3 snapshot. The new UI uses the same two JSON endpoints and needs no engine changes or new service. This package has not been published for you.
